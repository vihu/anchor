# anchor

A native Stremio client for Linux and macOS. It browses the addons in your
Stremio account and plays every stream in your own `mpv`, so your
`mpv.conf`, scripts and shaders apply.

Status: in development, not released yet (changes in `CHANGELOG.md`).

## Building

```bash
cargo run --release
```
